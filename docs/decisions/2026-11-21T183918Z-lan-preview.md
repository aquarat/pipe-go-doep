# LAN preview binding

Date: 2026-11-21T18:39:18Z
Status: accepted; extends the initial loopback-only workbench decision

The maintainer requested access from the entire LAN using `0.0.0.0`.

Allow explicit wildcard/private listen addresses through `serve -addr` and accept
private-IP HTTP Host headers. Same-origin validation continues to compare the
browser's Origin with the requested Host, allowing LAN render requests. The
preview is started with `-addr 0.0.0.0:8080` and opened at the host's private
address (for example `http://192.168.1.20:8080`). Launching without flags still
selects loopback.

This is a shared preview: the existing single concurrent render/validation slot
is shared by all clients. Each browser origin keeps its own editor draft.
